### GlamourLog

```
https://puni.sh/api/repository/croizat
```

This plugin adds a Glamour Log window to the game, in as-close-as-it-can-be style to the existing log windows in the game, but for glams!

<img width="911" height="644" alt="{BDCEEA90-ADE8-4F5A-86B9-AF531F6EBF2B}" src="https://github.com/user-attachments/assets/2ade5b39-b974-4bd4-b7a3-1ef03fd76817" />

It tracks all "outfits" (the feature introduced in Dawntrail to consolidate multiple glam pieces into one outfit) in the game, and whether or not you have them stored in either the dresser or the armoire. You can see precisely how to acquire any outfit, and start collecting them all to watch the numbers go up.

Inside the main window is a help button that will open the Guide window and has info on everything the plugin has to offer, and how it works.

The plugin also comes with some other glam-related tweaks such as Chat Alerts, Loot Alerts, Quick Storing, and Filtering. And possibly more in the future.
